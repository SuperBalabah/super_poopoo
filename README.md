# Super Poopoo Radar 🛰️

獨立客製化 Pokémon GO 即時雷達與本地色違比對系統 (PWA)。

## 🌟 特色
1. **即時官方資料對接**：直連 Pogocoordinates 伺服器，100% 同步真實野怪刷新、IV、CP、等級與座標。
2. **繁體中文 & 編號搜尋**：支援輸入中文（如：快龍、皮卡丘、班基拉斯）或編號（如：149、25）。
3. **地點快捷記憶**：自訂儲存常用地點（我家、公司），永久保存在本機。
4. **IV 快捷切換**：100% (滿完美)、98%+、90%+、0% (稀有廢柴)。
5. **本地 64-bit 色違雜湊比對**：輸入個人的 Trainer Seed，全在本地瀏覽器比對，隱私零外流。
6. **跨平台 PWA**：筆電常駐桌面、手機免裝商店直接「加入主畫面」。

## 🚀 啟動方式

### 💻 本地極速啟動 (筆電 & 手機區域網路直連，即時穿透)
```bash
node server.js
```
- 筆電端瀏覽：`http://localhost:3000`
- 手機端瀏覽：`http://<您的區網IP>:3000` (同一 Wi-Fi 下免任何外網限制)
